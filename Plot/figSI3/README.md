# FigSI3 basis mismatch trajectories

This folder contains the Python redraw package for the one-row, five-panel
trajectory figure: Mutualistic, Chua x1, Chua x2, Chua x3 and Chua 3D. Run
from this directory with:

```powershell
python code\plot_si3.py
```

The script reads only `plot_data` and writes the complete figure plus panels
a–e to `code/output` as editable SVG/PDF and 600-dpi PNG/TIFF files.
