# Schematic asset provenance

data.  It is derived from Wikimedia Commons, [File:Brain-outline-lateral.svg](https://commons.wikimedia.org/wiki/File:Brain-outline-lateral.svg),
which is marked CC0 1.0 Universal Public Domain Dedication.  The network
marks drawn over it by `plot_panel_a.py` are generated schematic elements.
