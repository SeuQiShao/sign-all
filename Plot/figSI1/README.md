# FigSI1 scale robustness

This folder contains the Python redraw package for the 2 × 5 scale-robustness
SI figure. Run from this directory with:

```powershell
python code\plot_si1.py
```

The script reads only `plot_data` and writes the complete figure plus panels
a–e to `code/output` as editable SVG/PDF and 600-dpi PNG/TIFF files.
