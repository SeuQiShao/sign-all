# Supplementary Table S19 source data

This directory stores the SST prediction comparison with simple baselines over
the 24-month held-out interval. `summary.csv` reports mean MAPE, RMSE, MAE, and
DeltaX RMSE for SIGN, persistence, AR(12), and monthly climatology.

The current SIGN row is MAPE = 3.651%, RMSE = 1.140, MAE = 0.938, and
DeltaX RMSE = 0.585. Lower values indicate better performance.
