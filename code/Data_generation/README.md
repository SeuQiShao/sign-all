# Data generation

This folder provides reproducible generators and adapters for the datasets
used by SIGN.

## Main entry points

- `generate_dataset.py`: create one time-major synthetic trajectory;
- `dynamics.py`: benchmark equations and parameter specifications;
- `graph.py`: scale-free, small-world, random, and structured graph builders;
- `integrate.py`: numerical integration utilities;
- `robustness.py` and `generate_robust.py`: observation, sampling, topology,
  heterogeneity, basis-mismatch, and adjacency-corruption cases;
- `make_benchmark.py`: create a benchmark batch from a configuration;
- `prepare_npz_for_e2v3.py`: convert `[time,node,dimension]` NPZ data to the
  canonical `[node,time,dimension]` PyG layout;
- `prepare_fhn_prediction.py`: prepare the 1,000-node FHN prediction example;
- `prepare_sst_dataset.py`: convert an SST PyG object or dense array while
  preserving the source graph and time coordinate;
- `prepare_empirical_networks.py`: convert raw edge files on demand without
  modifying the archived originals.

## NPZ convention

Public trajectories use `x=[time,node,dimension]`, `t=[time]`,
`edge_index=[2,edge]`, and optional `edge_weight`. Edges follow
`edge_index[0] -> edge_index[1]`. Metadata is stored in a JSON sidecar and in
the NPZ when generated by the public utilities.

```powershell
python Data_generation/generate_dataset.py `
  --system rossler --network small_world --num-nodes 64 `
  --num-steps 256 --dt 0.01 --out SIGN-data/synthetic/rossler_smoke.npz
```

The canonical E2V3 trainer uses its original PyG dataset interface. Use the
NPZ adapter when a generated robustness case needs to enter `SIGN-phase`.

FHN and SST preparation scripts are kept separate because the experiments use
different graph/data sources. The large FHN protocol is based on the existing
`bn-human` partition workflow and produces 22,198 nodes; the public package
includes the 1,000-node smoke example only. The SST adapter supports the
71,987-node, 120-step graph trajectory supplied under `SIGN-data/prediction`.

Large synthetic trajectories are not committed. Use the generation scripts
with the parameters in `Sign-Robust/configs` or the manuscript. Empirical
network downloads are described in `Empirical_networks/README.md`.
