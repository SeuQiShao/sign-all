# Data and external comparison code

The MIT license in `LICENSE` applies to SIGN-authored source code only. It
does not automatically apply to input data or external software.

## Distributed data

- `SIGN-data/synthetic/` contains smoke trajectories generated by the public
  SIGN data-generation code.
- `SIGN-data/prediction/fhn_2d.npz` is a smoke-scale FHN example generated by
  the public preparation script.
- `SIGN-data/prediction/sst_enso_71987.npz` is the supplied ENSO/SST
  trajectory converted to the public NPZ layout. It is a publicly released
  cleaned derivative of the public SSTG dataset; its attribution and license
  information are recorded in `SIGN-data/prediction/SST_PROVENANCE.md`.

## Empirical networks

Raw empirical networks are intentionally not distributed. Download them from
the sources listed in the manuscript's Data Availability statement, retain
the provider's citation and license, and prepare them locally as described in
`Empirical_networks/README.md`. The same applies to the `bn-human` source and
the 22,198-node FHN partition.

The manuscript's empirical-network set comprises the voles social network,
human and mouse gene-regulatory networks, human and fly brain networks, the
GitHub collaboration network, and Catster. The manuscript points to the
Network Repository and the Stanford Large Network Dataset Collection (SNAP)
for these sources and cites them as refs. [33], [41]–[44] in the manuscript
and [S10], [S13] in the SI. These source citations and terms remain with the
original providers.

## Baselines and dependencies

This repository contains SIGN implementations and protocols only. It does not
include MTGNN, ASTGCN, MSTGCN, STSGCN, STGCN, STGNN-family, Two-Step,
TP-SINDy, LaGNA, or other baseline implementations. The external traffic
baselines (including the STGNN-family comparison) were obtained from the
unified GitHub benchmark repository STG4Traffic:
https://github.com/trainingl/STG4Traffic . Its repository and the individual
upstream projects retain their own licenses and citations; those baselines
are not silently reimplemented or included in this release.

The Gumbel-Softmax helper in `SIGN-phase/model/utils.py` is adapted from the
PyTorch implementation linked in its docstring.  That upstream attribution is
kept in the source and should remain with any redistribution of the code.
